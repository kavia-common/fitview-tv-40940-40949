This package contains UI components for the Fitness TV app:
- home/HomeFragment.kt : Leanback Browse home with rows and voice search
- player/PlayerActivity.kt : ExoPlayer-based video playback with overlay
- profile/ProfileFragment.kt, GoalsFragment.kt : dialogs to edit profile and goals
- search/SearchFragment.kt : voice and text search dialog
- widgets/ : Presenters for cards and chart
